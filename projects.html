Featured Project · Web Application

EyeWatch 2026

Framework: Next.js (App Router) · TypeScript · Tailwind CSS

View on GitHub

EyeWatch is a web-based, real-time student activity and engagement monitoring prototype built to give educators visibility into online classroom participation. It tracks student focus, meeting duration, and active tab states without intrusive surveillance.

/student

Student Activity Tracker

Automated Focus Tracking: Uses the Page Visibility API to automatically detect when a student is actively viewing the class tab versus navigating away or minimizing.

Session Metrics: Live timer showing real-time duration spent in class.

Simulator Controls: Interactive activity toggle (Active, Browsing, Idle, Screen Sharing) for testing.

/teacher

Teacher Dashboard

Live Overview: Aggregate class metrics showing total connected students, overall active engagement percentages, and session length.

Color-Coded Status: Live status indicators (Green = Active, Yellow = Idle, Red = On External Tab/Away) for every participant.

Attention Alerts: Flags students who have been away or inactive for extended periods.
